# 프로젝트 소개
소르테크 지원을 계기로 제작 중인 개인 프로젝트입니다.

AI + Java + Spring Boot를 기반으로 기업 홈페이지 형태의 웹 서비스를 구현하고 있으며
채용공고, 공지사항, 자유게시판 등의 기능을 개발하고 있습니다.

# 현재 진행 상황

## 구현 완료

- Spring Boot 프로젝트 기본 설정
- MySQL 데이터베이스 연동
- 회원가입 기능
- BCrypt 기반 비밀번호 암호화
- 로그인 기능
- Spring Security 인증 및 권한 설정
- 일반 사용자(USER) / 관리자(ADMIN) 권한 구조
- 메인 홈페이지 구현
- 자유게시판 CRUD 구현
    - 게시글 작성
    - 게시글 목록 조회
    - 게시글 상세 조회
    - 게시글 수정
    - 게시글 삭제
- 자유게시판 작성자 본인 확인을 통한 수정/삭제 권한 처리
- 공지사항 CRUD
- 채용공고 CRUD
- 일반 사용자 / 관리자 기능 구분 강화
- Validation
